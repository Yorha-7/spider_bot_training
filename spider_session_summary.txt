--------------------------------------------------------------------------------
WHAT WE BUILT
--------------------------------------------------------------------------------

1. REWARD FUNCTIONS (spider_env.py)
   - 9 original reward terms for velocity tracking
   - Linear velocity tracking (track_lin_vel_xy_exp)
   - Yaw rate tracking (track_ang_vel_z_exp)
   - Joint torque, acceleration, action rate penalties
   - Flat orientation, feet air time, energy rewards


2. CONFIGURATION (spider_env_cfg.py)
   - 11 reward scales
   - Robot USD path
   - Physics simulation settings
   - Event randomization


3. TELEOP FEATURES (spider_env.py)
   - set_teleop_mode(enabled) - Enable manual control
   - set_commands_from_keyboard(lin_x, lin_y, ang_z) - Set velocity
   - set_commands(tensor) - Direct command setting


4. PLAY SCRIPT (scripts/rsl_rl/play_teleop.py)
   - --fixed_velocity argument for fixed velocity commands
   - Example: --fixed_velocity 0.3 0 0.5


5. UTILS (source/spider/spider/utils/)
   - keyboard_input.py - Keyboard handler (fallback mode)

--------------------------------------------------------------------------------
TELEOP USAGE EXAMPLE
--------------------------------------------------------------------------------

    --task spider_2 \
    --checkpoint <path_to_model> \
    --num_envs 1 \
    --fixed_velocity 0.3 0 0.5


Where: --fixed_velocity LIN_X LIN_Y ANG_Z

Examples:
  Forward only:     --fixed_velocity 0.3 0 0
  Forward + Turn:   --fixed_velocity 0.3 0 0.5
  Backward:        --fixed_velocity -0.3 0 0
  Turn only:       --fixed_velocity 0 0 1.0
